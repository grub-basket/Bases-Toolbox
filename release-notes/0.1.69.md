Autocomplete in every field that names something in your vault, plus the unfinished-import reminder's Ignore button (0.1.68, released here for the first time).

## 0.1.69 — Autocomplete everywhere

- **One shared suggester (`src/suggest.ts`).** The previous `ListInputSuggest` and folder suggester are folded into one `AbstractInputSuggest`-based module. Matching is case-insensitive and order-independent (every typed word must appear), with exact and prefix matches ranked first. Vault scans run lazily when a list first opens and are reused while it stays open.
- **Folder fields suggest folders** — companion-note destination and folder lists, the timestamp stamper's folder scope, inline-field migration scope, the CSV importer's target folder, and the New note window's folder. Empty folders are offered too; `/` is no longer offered as a target.
- **Property fields suggest property names** — bulk edit, property fork (name, edit source, edit fork), rollup and sync-formula source/target, the property-index rename prompt, CSV import column mapping and composite property names, and the stamper's created/modified properties.
- **Value fields suggest values for the chosen property**, most-used first — bulk edit values (per line in list mode), the New note list editor (per line or `;` item, instead of overwriting the whole list; `tags` also offers inline `#tags`). When the property changes while the list is open, the value list rebuilds for the new property.
- **List fields complete only the item under the cursor** (`a, b, c`, space-separated, or one per line) and hide items already in the list.
- **Other suggestions:** file extensions in the skip/exclude lists and the excluded-extension add box, `{{column}}` / `{{date}}` / `{{time}}` / `{{now}}` variables in the importer's filename and composite patterns (without doubling the closing `}}`), saved preset names, and existing `.base` files in the import folder (with a "will be reused" hint).
- **Picking a suggestion commits exactly like typing** — `input` and `change` events bubble to the whole form, so, for example, the CSV importer's draft autosave now picks up values chosen from a list.
- The conditional-formatting property/value lists keep showing every entry (never truncated); other lists cap at 100. Existing value lists now narrow as you type instead of always showing the full list.
- Unused file/tag suggester helpers removed after the rollout; matching is on the value only.

## 0.1.68 — Ignore button on the unfinished-import reminder

- The startup "You have an unfinished CSV import…" notice now offers **Ignore**, which mutes it without discarding the draft (a `dismissedAt` stamp; the reminder returns only if a newer draft is saved). The draft stays restorable from inside the importer.
