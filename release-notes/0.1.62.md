A new command plus two feature rounds, bringing the public build up to date since 0.1.59.

## 0.1.62 — Sync formula into property

- **Sync formula into property.** A new command (and launcher entry) that writes a base's *computed* formula column into a real frontmatter property on every note in the current view — so a value that only existed as a live formula becomes a stored property you can sort, filter, group, or reuse anywhere. Pick the formula, name the property; it evaluates through Bases' own engine, skips reserved property names, and is one-shot and fully revertible from history (re-run to refresh). It mirrors **Compute rollup into property** across the command palette, launcher, in-app reference, and history — the sibling for computed columns instead of linked notes.

## 0.1.61 — Duplicate finder: merge into a new note

- **Merge a duplicate group into a brand-new note.** When none of the copies deserves to be the survivor, a second button per group combines every ticked note into a new note instead. It lands in the oldest note's folder as `<name> (merged)`, inherits the oldest `created` and a fresh `modified`, takes the oldest note's value on property conflicts, concatenates the bodies oldest-first, re-points backlinks, and trashes the sources. Unticked notes are left alone. Revertible from history: the sources come back, and the new note is emptied rather than deleted. The new note opens when it is done.

## 0.1.60 — Duplicate finder feedback + importer

- **Duplicate finder feedback round.** Merged notes inherit the oldest member's `created` and a fresh `modified` when the notes carry date frontmatter, and the preview says so. Keep/tick selections survive switching between the To review and Ignored tabs. Unique-ID filenames (letters plus a long number) no longer collapse into one bogus group; only short trailing numbers like `Meeting notes 2` still fold. Trashed notes list one full path per line. Preview details read one per line, without repeating near-identical filenames in two-note groups. Diffs are labelled pairwise, with a note that merging appends bodies whole. The view is wider (720 to 1200px).
- **Importer:** an optional "Add a created property" toggle (off by default) stamps `created: <import time>` on newly created notes; a sheet's own created column wins, and update mode is untouched. The body template now documents itself with a collapsible rules-and-example block.
