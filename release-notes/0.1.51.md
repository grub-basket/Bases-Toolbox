# 0.1.51

- **Community-plugin review cleanup.** Housekeeping to match the Obsidian plugin guidelines:
  - Removed two informational `console.log` messages that fired during the one-time data-migration.
  - Switched cross-window-unsafe `instanceof HTMLInputElement` checks to Obsidian's `.instanceOf()`, so type checks stay correct inside popout windows.
  - Used `createDiv()` instead of `createEl("div")` in the reference panel.
  - The **Open settings** and **Open launcher** commands no longer repeat "Bases Toolbox" in their names — Obsidian already shows the plugin name next to every command.
