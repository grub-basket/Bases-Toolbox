Two kanban / view-type quality-of-life additions.

## 0.1.64 — Kanban hide-empty-columns button + hide view types

- **Kanban: one-click "hide empty columns."** Bases has a `hideEmptyGroups` option for kanban views, but it lives in the view-options menu. This surfaces it as a toolbar button on kanban bases (and a command, for a hotkey): one click hides the columns with no cards, another brings them back. The button appears only while a kanban view is on screen and shows the current state. It's a plain reversible view-config toggle — a second click undoes it — so it isn't recorded in history.
- **Hide view types from the picker.** A new opt-in setting hides chosen Bases view types (Table / Cards / List / Kanban, plus any a plugin registers) from the view-type picker — both the native "Add view" / change-type menu and Bases Toolbox's own add-view dropdown — for when a community plugin shares a native type's name and the duplicate in the picker is confusing. The type keeps working on any existing views of it; it's only removed from the picker. The native-menu filter is deliberately conservative: it only trims a menu that is entirely a type picker, so it can never remove a real view from the view switcher. Nothing is hidden by default.
