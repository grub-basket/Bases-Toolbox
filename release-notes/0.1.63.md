Adds manual card ordering for Obsidian's Bases kanban view.

## 0.1.63 — Manual card order for kanban

- **Manual card order for a base's kanban.** Bases orders the cards inside each kanban column by the base's sort, so a card dragged into place has no persistent position — reload and it snaps back, because the kanban has nowhere to store a manual order. This command fixes that: it gives the base a numeric order property, seeds it **spaced** (10, 20, 30… so a card can be slotted between two others without renumbering the column) from a basis you pick — creation date, modification date, file name, or the current display order — and points every kanban view's sort at that property. Each column then has a real, editable, **persistent** order: change a card's order value and the card moves, and it stays put across reloads. Re-run the command any time to reseed from a fresh basis. Available as a command, a launcher entry, and in the in-app reference; both the seeded values and the sort change are revertible from the bulk file change history as two independent entries.
