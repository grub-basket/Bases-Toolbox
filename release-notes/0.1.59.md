Performance release for slow and network-mounted vaults.

- **Much faster plugin load.** Starting the plugin used to make ~45 filesystem round-trips (history files + settings buckets) one after another, *before* reporting itself loaded — invisible on an SSD, but seconds on a network drive, which triggered Obsidian's "plugin took a long time to load" flag. The plugin now registers everything instantly and loads its data immediately afterwards, in parallel batches instead of serially.
- Safety holds during the brief load window: saves wait for the data to arrive first (an early save can never overwrite real settings with defaults), and undo/history wait for the load before acting.
