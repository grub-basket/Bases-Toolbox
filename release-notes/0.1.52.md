# 0.1.52

- **New — View manager.** One dialog for all of a base's views, replacing Obsidian's four-levels-deep flow (view menu → the edit arrow → a three-dot menu → Duplicate → name it). Every view is listed in switcher order, with:
  - **Rename in place** — type over the name, press Enter.
  - **Duplicate** — copies the *whole* view: columns, order, sort, filters, limit, card size, image property and any other settings it carries.
  - **Reorder** with up/down, and **Make default** to move a view to the top (the one a base opens on).
  - **Show** — switches the open base tab to that view.
  - **Add a view**, choosing from the view types Bases currently offers.
  - **Delete**, behind a confirmation.
- **Three ways in:** a button next to the base's own view switcher, the command **"Manage views for this base"**, and a launcher tool.
- **Everything is revertible** from the bulk file change history — including a deleted view, which comes back with all of its settings.
- Duplicate names are automatically suffixed, since Bases identifies a view by its name. Renaming or deleting the view you're currently looking at re-points the open tab, so it never ends up on a view that no longer exists.
- **Bulk file change history** now describes whole-file changes generically rather than assuming every one is a note merge — a base edit offers "Revert this change" instead of "Revert merge".
